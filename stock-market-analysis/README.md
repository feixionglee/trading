# 美股市场分析

## 文件位置

提示词、任务清单和说明保存在 `feixionglee/trading` 仓库；云端工作目录为 `/workspace/trading`。历史报告和新报告保存在 `/workspace/stock-market-analysis/YYYY-MM-DD/`，不纳入仓库。原始本地配置和运行记忆保留在仓库外的 `migration/original/automations/`。仓库提示词已去除账户末四位和旧线程 ID。

## 运行方式

这是供具备行情、新闻和授权账户工具的 AI 任务执行的提示词，没有独立应用程序、依赖安装或常驻服务。先检查实际运行环境中可用的工具，再按所选提示词执行。只做分析，不下单、不撤单、不修改自选股。缺少实时数据时明确写入报告，不以历史数据替代。

任务尚未注册到云端调度器，`jobs.json` 是交接清单，不是某个调度器的导入格式。须在支持当前云环境的调度界面选择此环境，以仓库中对应提示词建立任务，然后验证手动和定时运行。确认云端任务正常后再停用 Mac 上的同名任务，切换时防止重复运行。

## 时间

原配置为周一至周五 UTC 12:30（盘前）和 19:00（收盘前），提示词保留原时间说明。这在夏令时对应美东 08:30 和 15:00，冬令时对应 07:30 和 14:00。

若需全年保持常规开盘前一小时、收盘前一小时，应在调度器使用 `America/New_York` 的 08:30、15:00，并同步更新提示词中的触发时间说明。任务须检查交易日；提前收盘日还需要交易所日历逻辑，固定时间不保证在提前收盘前运行。

## GitHub 与云环境

本地编辑、Git 提交、推送到 GitHub、发布环境快照和激活调度是不同操作。发布环境快照不等于推送代码，也不会自动启用任务。使用当前 checkout；云任务已隔离，无需创建 Git worktree。

更新仓库前先用 `git status` 检查本地改动。工作区干净且远端分支明确时可使用 `git pull --ff-only`；有改动或分叉时先处理，不要强制重置。推送前检查暂存内容只包含配置和说明。
